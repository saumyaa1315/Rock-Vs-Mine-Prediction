# Rock-Vs-Mine-Prediction
This machine learning project uses sonar signal data to classify objects as either rocks or mines. It applies data preprocessing, feature engineering, and model training using Python libraries such as scikit-learn, pandas, and NumPy, achieving accurate binary classification through supervised learning techniques.

# Project Overview

- Objective: Use supervised learning models to classify sonar signals as either rocks or mines.
- Tools Used: 
  - Python
  - Google Colab
  - scikit-learn
  - pandas
  - NumPy
  - Matplotlib / Seaborn (for visualization)

#Features

- Data preprocessing and cleaning  
- Feature selection and exploration  
- Model training and evaluation  
- Performance metrics (accuracy, confusion matrix, etc.)

#Dataset

- Source: Kaggle
- Contains 208 samples, each with 60 features (sonar readings)

#How to Run

1. Open the Colab notebook (`rock_vs_mine.ipynb`) in Google Colab.
2. Run all cells step by step.
3. Review the outputs and model evaluation results.

#Results

We applied supervised learning models like logistic regression, decision trees, and random forests, achieving good classification accuracy on test data.
